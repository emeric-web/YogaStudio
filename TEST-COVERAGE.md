## Coverage Scope

- Backend coverage targets `src/services/**/*.ts` and is generated by Vitest.
- Frontend coverage targets the application source files and is generated by Vitest.
- E2E coverage measures frontend code executed in the browser by Cypress.

## Reproduce the Reports

From `backend/`:

```bash
npm run test:coverage
```

From `frontend/`:

```bash
npm run test:coverage
npm run test:e2e
```

The E2E command starts the dedicated PostgreSQL database, the backend, and the instrumented frontend before running Cypress and checking the 80% thresholds.
